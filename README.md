# Qoka models

Models that Qoka Home downloads for memory cleanup. Files are attached to the releases.

- `qoka-memory-iter04-Q6_K-*.gguf`: Qwen3-4B-Instruct-2507 fine-tuned to judge duplicate memory nodes, Q6_K, in two parts. Load the first part with llama.cpp.
- `Qwen3-Embedding-0.6B-Q8_0.gguf`: Qwen3-Embedding-0.6B, unchanged.

The base models are by the Qwen team; see their model pages for license terms.
